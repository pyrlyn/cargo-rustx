# Лайфтаймы в возвращаемом типе

## Как есть (Rust)

```rust
fn first<'a>(xs: &'a [Item], key: &str) -> &'a Item
```

## Как хочется

```rust
fn first(xs: &[Item], key: &str) -> &from(xs) Item
```

## Реализация

Атрибутный макрос вводит именованный лайфтайм и привязывает его к параметру из `from(..)`.
